# despliegue-daw

Proyecto del módulo **Despliegue de Aplicaciones Web (0614)** · 2.º DAW · Ismael Domingo Navarro

## Alojamiento elegido (Sesión 1)

Cloud (IaaS) en DigitalOcean: servidor virtual + base de datos gestionada, porque permite automatizar el despliegue con GitHub Actions y ampliar los recursos en épocas de mucho tráfico pagando solo por uso.

## Entorno de prácticas

Máquina virtual `servidor-daw` en VirtualBox con Ubuntu Server 26.04 LTS, red en modo puente (Bridged) y acceso por SSH.
